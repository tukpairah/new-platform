Put this mode's music here: MP3, Latin filenames, no spaces. One folder per mode: audio/games/<modeId>/.
Then list the files in content/games.js ("music": ["audio/games/<modeId>/a.mp3"]) or use the admin Games tab (upload, reorder, test-play).
Tracks play in random order, never the same one twice in a row. No files = defaultMusic, then the lobby music.
